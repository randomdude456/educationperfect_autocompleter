# Changelog

## 5.1.1

- Added an optional **Auto-fill answer box** setting.
- Auto-fill is OFF by default.
- Auto-fill never presses Enter, Submit, Continue, or Next.
- Added a clear warning that no automation can be guaranteed ban-proof.

## 5.1.0

- Replaced automatic answering with manual-submit assistant mode.
- EP Helper now only shows the matching answer.
- Added **Copy** and **Fill answer box** buttons.
- Removed automatic Submit, Enter, Continue, Next, and page navigation.
- Kept reveal-delay, cooldown, and 100% / 80% / 60% coverage settings.
- Simplified the UI around one answer card.
- Kept all diagnostics inside the extension panel; no console debugging.

## 5.0.3

- Restricted automation to the game page and used explicit EP controls only.
