# EP Auto Answer v4.2.0

EP Auto 4.2 focuses on a simpler interface, Unicode-safe vocabulary matching, and a more reliable automation flow.

## Highlights

- Beginner-friendly in-page controls.
- Unicode-safe matching for Japanese, kanji, accented text, and other non-ASCII languages.
- Reliable `Fill → Enter/Submit → EP result → Next` flow.
- Auto Next waits until the current answer has been submitted.
- Stops on a rejected answer instead of endlessly retrying.
- Improved support for Education Perfect's hybrid React/Angular interface.
- Beginner-focused Chrome installation documentation.

## Download

Download `EP-Auto-Answer-v4.2.0.zip` from the release assets, extract it, then install `EP-Auto-Answer.user.js` with Tampermonkey or Violentmonkey.
